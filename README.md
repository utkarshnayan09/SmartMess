 # Smart Mess Management System

A simple and smart solution to improve the college mess experience, with a main focus on **reducing long queues and waiting time**.

## The Problem

During breakfast, lunch, and dinner, college messes often become overcrowded. Students have to stand in long queues without knowing how crowded the mess is or how long they might have to wait.

## Our Solution

Our platform gives students a way to **check the current queue status and estimated waiting time** before going to the mess.

It also provides a common platform for students and mess administrators to manage everyday mess activities.

### Key Features

* Real-time queue and crowd status
* Estimated waiting time
* Daily mess menu
* Student feedback and ratings
* Complaint management
* Mess announcements
* Admin dashboard for managing the system

## Tech Stack

* **Frontend:** Next.js, TypeScript, Tailwind CSS
* **Backend & Database:** Supabase
* **Design:** Figma

## How It Helps

The main goal is simple: **less waiting and better crowd management**.

By giving students real-time queue information and giving administrators better visibility, the system can make the mess experience more convenient and organized.

## Future Scope

We plan to add features such as AI-based crowd prediction, peak-hour analysis, digital tokens, queue notifications, and food demand prediction.
